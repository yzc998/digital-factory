# 🏭 工厂数字孪生系统2

基于 Three.js 构建的浏览器端三维工厂可视化管控平台，不依赖任何后端服务，打开浏览器即可运行。

## 功能一览

| 模块 | 说明 |
|------|------|
| **三维场景** | 程序化生成工厂全貌：4 间厂房、办公楼、仓库、食堂、研发楼、配电房、门卫室 |
| **工业设施** | 储油罐群、烟囱、冷却塔、露天堆放区、旗杆、围栏 |
| **交通系统** | 主干道 + 支路网、人行道、停车场（带标线）、路灯 |
| **动态元素** | 小汽车、叉车、卡车、30+ 人员（工人/工程师/安保/管理） |
| **绿化景观** | 60+ 树木、灌木丛，沿道路及厂区周边分布 |
| **休闲设施** | 篮球场（含球架、边线） |

## 交互操作

- **左键拖拽** — 旋转视角
- **滚轮** — 缩放拉近拉远
- **右键拖拽** — 平移场景
- **左键单击** — 点击任意对象弹出信息面板（类型/名称/编号/位置/尺寸/状态）
- **ESC / 点击面板外** — 关闭信息面板

## 操作面板（左侧）

- **视角控制** — 一键切换透视 / 俯视 / 复位，带平滑过渡动画
- **鸟瞰小窗** — 显示/隐藏右下角正交俯视视图
- **环境亮度** — 滑动条实时调节光照强度
- **场景概览** — 建筑/车辆/树木/人员/总对象数实时统计
- **功能介绍** — 操作指引
- **系统信息** — 版本号、运行时间

## 材质系统

所有纹理由 Canvas 实时程序化生成，无需外部图片：

- 波纹金属板（厂房墙面）
- 混凝土（办公楼、门卫室）
- 红砖墙（仓库、食堂）
- 锈蚀金属（储油罐）
- 沥青路面 / 人行道砖 / 瓦楞屋顶 / 玻璃幕墙

## 技术栈

- **Three.js** — 3D 渲染引擎
- **OrbitControls** — 视角控制器（旋转/缩放/平移）
- **Raycaster** — 射线点击拾取
- **Canvas API** — 程序化纹理生成
- **ES Modules** — 模块化代码结构

## 使用方法

1. 使用任意静态服务器打开 `index.html`：

```bash
npx serve .
# 或
python -m http.server 8080
# 或 VS Code Live Server
```

2. 浏览器访问对应地址即可。

> 也可直接双击 `index.html` 通过 `file://` 协议打开（部分浏览器可能需要允许本地文件加载模块）。
